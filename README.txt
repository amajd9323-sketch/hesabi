حسابي Pro 3.2 — إصلاح نهائي لمشكلة الطباعة
===========================================
هذه النسخة أزالت التشغيل التلقائي للطباعة بالكامل، وأزالت CSS الخاص بالطباعة من الصفحة.
عند فتح index.html ستظهر لوحة التطبيق مباشرة.

ملاحظة:
- افتح index.html مباشرة.
- إذا كان المتصفح يعرض شاشة الطباعة القديمة، أغلق تبويب/نافذة الطباعة ثم افتح index.html في تبويب جديد.
- PWA/Service Worker يعملان عند التشغيل عبر localhost أو HTTPS.
- النسخة الحالية تركّز على تشغيل التطبيق بشكل صحيح. تفاصيل الفواتير تظهر داخل التطبيق بدل فتح نافذة طباعة تلقائية.
